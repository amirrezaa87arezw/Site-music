# سایت رسمی سایکو (PSYCHO)

سایتی حرفه‌ای برای معرفی و انتشار موزیک، با:
- هیرو سه‌بعدی متحرک (Three.js) با رنگ‌بندی بنفش-قرمز مطابق هویت برند
- پلیر موزیک سراسری (نوار پایین صفحه، در همه صفحات فعال)
- پنل مدیریت کامل: آپلود موزیک، مدیریت ادمین‌ها (مدیر اصلی می‌تواند ادمین جدید بسازد)، و صفحه‌ی لاگ/دیباگ
- کاملاً فارسی و راست‌چین (RTL)، ریسپانسیو برای موبایل و دسکتاپ

## ۱. اجرای محلی (روی سیستم خودت)

```bash
# نصب پکیج‌ها
npm install

# فایل env بساز
cp .env.example .env
# سپس مقادیر SESSION_SECRET و SUPER_ADMIN_USERNAME/PASSWORD را داخل .env عوض کن

# ساخت دیتابیس
npx prisma db push

# ساخت اولین مدیر اصلی (بر اساس مقادیر داخل .env)
npm run db:seed

# اجرای سایت در حالت توسعه
npm run dev
```

سایت روی `http://localhost:3000` بالا می‌آید و پنل مدیریت روی `http://localhost:3000/admin/login`.

## ۲. ساختار پروژه (خلاصه)

```
src/app/                 صفحات سایت (Next.js App Router)
  page.js                صفحه اصلی
  admin/login             ورود ادمین
  admin/(dashboard)        پنل مدیریت (محافظت‌شده با ورود)
  api/                    مسیرهای بک‌اند (ورود، آهنگ‌ها، ادمین‌ها، لاگ‌ها)
src/components/          کامپوننت‌های رابط کاربری
src/lib/                 ابزارهای مشترک (احراز هویت، لاگر، آپلود فایل، دیتابیس)
prisma/schema.prisma     ساختار دیتابیس (Admin, Track, Log)
public/uploads/          محل ذخیره فایل‌های صوتی و کاور آپلودشده
```

## ۳. آپلود روی Railway (میزبانی رایگان ۳۰ روزه)

1. یک ریپازیتوری گیت‌هاب از این پروژه بساز و کد را در آن push کن.
2. در [railway.app](https://railway.app) وارد شو → **New Project** → **Deploy from GitHub repo** → ریپازیتوری را انتخاب کن.
3. در تب **Variables** پروژه، این متغیرها را اضافه کن:
   - `DATABASE_URL` = `file:./prisma/dev.db`
   - `SESSION_SECRET` = یک رشته طولانی و تصادفی (مثلاً از یک تولیدکننده پسورد آنلاین)
   - `SUPER_ADMIN_USERNAME` = نام کاربری دلخواه برای مدیر اصلی
   - `SUPER_ADMIN_PASSWORD` = رمز عبور قوی
4. برای اینکه اطلاعات (دیتابیس و فایل‌های آپلودی) بعد از هر دیپلوی از بین نرود، در تب **Volumes** یک Volume جدید بساز و آن را روی مسیر `/app/prisma` و یک Volume دیگر روی مسیر `/app/public/uploads` مانت کن. **این مرحله خیلی مهم است** — بدون آن، هر بار که دوباره دیپلوی کنی موزیک‌ها و اکانت ادمین پاک می‌شوند.
5. Railway به‌صورت خودکار از `package.json` دستور build (`npm run build`) و start (`npm start`) را اجرا می‌کند.
6. بعد از اولین دیپلوی موفق، از تب **Deployments → View Logs**، یک بار این دستور را از طریق Railway CLI یا Shell اجرا کن تا مدیر اصلی ساخته شود:
   ```bash
   npm run db:push
   npm run db:seed
   ```
   (اگر Railway CLI نصب داری: `railway run npm run db:seed`)
7. آدرس داده‌شده توسط Railway را باز کن، وارد `/admin/login` شو و با نام کاربری/رمزی که در مرحله ۳ گذاشتی وارد شو.

## ۴. بعد از ورود به پنل مدیریت

- **مدیریت موزیک‌ها**: عنوان، هنرمند، فایل صوتی و کاور را آپلود کن. می‌توانی یک آهنگ را به‌عنوان «آخرین انتشار» علامت بزنی تا در صفحه اصلی نمایش داده شود.
- **مدیریت ادمین‌ها** (فقط مدیر اصلی): می‌توانی ادمین‌های جدید با نقش «ادمین معمولی» یا «مدیر اصلی» اضافه یا حذف کنی.
- **لاگ‌ها**: هر ورود، آپلود، خطا و رویداد مهم دیگر اینجا با زمان دقیق ثبت می‌شود — برای دیباگ و بررسی مشکلات.

## نکات امنیتی

- حتماً `SESSION_SECRET` و رمز مدیر اصلی را طولانی و غیرقابل حدس انتخاب کن.
- بعد از اولین ورود، پیشنهاد می‌شود یک ادمین جدید با رمز دلخواه خودت بسازی و ادمین seed-شده را حذف کنی (یا رمزش را از طریق دیتابیس عوض کنی).
- حجم فایل صوتی حداکثر ۲۵ مگابایت و کاور حداکثر ۵ مگابایت است (قابل تغییر در `src/lib/upload.js`).
